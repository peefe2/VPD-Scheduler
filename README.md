# VPD Scheduler

머신러닝 기반 수증기압차(VPD) 예측 모델 구축 및 스마트팜 의사결정 지원 캘린더 서비스 (졸업과제)

온실의 온도·습도·CO2로 VPD를 계산하고, 날짜별로 적정 대역 안에 있던 시간을 캘린더로 돌아보게 합니다.
+1h/+3h/+6h 뒤 VPD 예측은 **그 온실 실측으로 "현재 값을 그대로 쓰는 방법(persistence)"보다 낫다고
확인된 뒤에만** 보여줍니다. 설비를 자동으로 제어하지 않으며, 조치는 항상 사람이 결정합니다.

설계·결정 사항과 근거 데이터는 [CLAUDE.md](CLAUDE.md)에 있습니다.

## 핵심 규칙

- **VPD 계산:** SVP = 0.6108·exp(17.27T/(T+237.3)), VPD = SVP·(1 − RH/100) kPa. 매 정시의 첫 실측값만
  쓰고(평균 아님), 빠진 정시는 보간하지 않습니다.
- **기본 적정 대역 0.5~1.5 kPa:** 문헌 근거로 정한 값이며, 온실 데이터에 맞춰 고르지 않습니다.
- **자동 전환:** 지평마다 처음 14일은 "학습 중", 이후 7일 단위로 판정해 3주 연속 개선이면 "모델 사용"
  (빨라야 35일째), 한 주라도 못하면 즉시 persistence로 돌아갑니다. CO2가 없는 온실은 모델을 쓰지
  않고, +6h는 참고용입니다.
- **성능 수치:** 화면에는 온실 하나씩 학습에서 빼고 잰 값(LOSO)만 씁니다. 연구 데이터 기준 +1h
  개선율은 일반 농가 6곳 +9.7%, 정밀 환경제어 온실 4곳 −10.9%입니다.
- **AI 어드바이저 가드레일:** 근거(사실 시트)에 없는 숫자, 등록하지 않은 설비, 단정적인 표현, 깨진 글자가 나오면
  막고 규칙 기반 안내로 바꿉니다. 대역을 벗어나는 시각은 예측하지 않습니다.

## 진행 상황

- **완료:** 온보딩·CSV 업로드, 캘린더, 모델 신뢰도·자동 전환, 오늘 화면, 수집 API(온실별 토큰 인증),
  재생 모드, AI 어드바이저(규칙 기반 + Gemini 연동, 기본 꺼짐), 적정 대역 변경 이력
- **진행 예정:** 작물·생육 단계 입력으로 적정 대역 추천(문헌 표 검토 중 —
  [research/band_literature.md](research/band_literature.md)), 푸시 알림, 웹 화면 로그인, 모바일 화면
- **알려진 한계:** 데이터가 가을·겨울뿐이라 여름 고VPD 위험이 덜 반영돼 있습니다. 실제 데이터의 대부분이
  대역 아래(과습)라 캘린더가 대체로 "대역 아래"로 보이는 건 버그가 아니라 데이터 그대로입니다.
  어드바이저의 조치 규칙은 초안이라 재배 전문가 검토가 필요합니다.

## 구조

```
backend/   FastAPI + SQLModel(SQLite) + pandas + LightGBM (uv, Python 3.12)
  app/       VPD 계산, 캘린더 집계, 예측·백테스트, 자동 전환, 오늘 화면, 어드바이저, 대역 이력
  models/    지평별 LightGBM 모델 (+ 데모용 온실별 제외 모델)
  tests/
frontend/  React 19 + Vite + TypeScript + react-router + TanStack Query
research/  모델 학습·검증 스크립트, 대역 추천용 문헌 표 초안
```

## 설치 (처음 한 번)

필요한 것: Git, [uv](https://docs.astral.sh/uv/), Node.js 20 이상

```
git clone https://github.com/peefe2/VPD-Scheduler.git
cd VPD-Scheduler/backend
uv sync
cd ../frontend
npm install
```

## 실행 (터미널 2개)

```
cd backend
uv run uvicorn app.main:app --port 8000
```

```
cd frontend
npm run dev
```

브라우저에서 http://localhost:5173 을 엽니다. Windows에서는 `--reload`를 붙이면 코드 변경 후 재시작이
멈추거나 예전 코드로 응답할 때가 있어, 시연 때는 빼는 편이 안전합니다.

### AI 어드바이저 LLM 켜기 (선택)

기본은 규칙 기반 안내만 합니다. Gemini 답변을 쓰려면 [Google AI Studio](https://aistudio.google.com/)에서
API 키(무료 등급)를 받아, 백엔드를 실행하는 PowerShell 창에서 환경변수를 넣고 실행합니다.

```powershell
$env:GEMINI_API_KEY = "<발급받은 키>"
$env:VPD_ADVISOR_LLM = "1"
cd backend; uv run uvicorn app.main:app --port 8000
```

키는 코드나 git에 넣지 않습니다. 모델은 `VPD_ADVISOR_MODEL`로 바꿀 수 있습니다(기본 `gemini-3.5-flash-lite`, 응답 약 4초).
LLM 답변은 "모델 사용" 상태 지평이 있을 때만 쓰이고, 가드레일을 통과하지 못하거나 호출이 실패하면
규칙 기반 안내로 대체됩니다. 무료 등급은 보낸 내용이 Google 제품 개선에 쓰일 수 있습니다(온실 측정값만 보냅니다).

## 시연: 재생 모드

실제 센서 대신 연구 데이터(farm3)를 날짜만 오늘로 옮겨 정시마다 흘려보냅니다.

1. 화면에서 새 온실 등록 — 데모 설정의 학습 온실에 `farm3_2023` 선택
2. 데이터 연결 단계에서 "재생 모드" 선택 → "토큰 발급"을 누르면 토큰이 들어간 명령이 나옵니다.
   세 번째 터미널에서 실행 (토큰은 그 화면에서 한 번만 보이니, 잃어버리면 재발급)

   ```
   cd research
   uv run --project ../backend python replay_ingest.py <온실 id> farm3_2023 --token <토큰>
   ```

   앞 35일 이력을 먼저 보내고, 이후는 실제 시계에 맞춰 매 정시 1건. `--speed 60`이면 1분에 1시간씩
   (표시 시각이 실제보다 앞서 나감). 멈추려면 Ctrl+C.

재생 온실은 모든 화면에 "재생 데이터, 이 온실의 실측이 아님" 안내가 뜹니다.
